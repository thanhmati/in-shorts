Đó chính là HTTP (Hypertext Transfer Protocol) — xương sống của toàn bộ mạng Internet:
1. Client gửi HTTP Request: Bao gồm Method (GET/POST/PUT/DELETE), Headers và Payload Body.
2. Server tiếp nhận, xử lý logic và phản hồi bằng HTTP Response.
3. Đi kèm Status Code kinh điển: 200 OK (Thành công), 201 Created, 401 Unauthorized, hay 404 Not Found.

Hiểu vững HTTP là nền tảng số một của mọi lập trình viên Web Frontend lẫn Backend!
